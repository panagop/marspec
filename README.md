# marspec

**Διερεύνηση της εξέλιξης των φασμάτων απόκρισης και σχεδιασμού σε κανονιστικά κείμενα. Αυτοματοποίηση με γλώσσα προγραμματισμού Python.**

🔗 **[marspec.streamlit.app](https://marspec.streamlit.app)**

---

## Περιγραφή

Το **marspec** είναι εφαρμογή για τον υπολογισμό φασμάτων απόκρισης και σχεδιασμού, βασισμένη στους παρακάτω αντισεισμικούς κανονισμούς:

- **Ε.Α.Κ. 2000** — Ελληνικός Αντισεισμικός Κανονισμός
- **Ευρωκώδικας 8 (EC8)**
- **Αναθεωρημένος Ευρωκώδικας 8 (prEN 1998)**

Ο χρήστης εισάγει τα απαραίτητα δεδομένα και η εφαρμογή υπολογίζει τις φασματικές επιταχύνσεις και σχεδιάζει τα αντίστοιχα διαγράμματα. Παρέχεται επίσης η δυνατότητα εισαγωγής αρχείων σεισμικών καταγραφών, με αυτόματη παραγωγή επιταχυνσιογραφήματος και ελαστικού φάσματος απόκρισης.

> **Τμήμα Πολιτικών Μηχανικών – Σχολή Μηχανικών**  
> Διεθνές Πανεπιστήμιο της Ελλάδος (ΔΙΠΑΕ), Σέρρες  
> *(Πρόγραμμα σπουδών ΤΕΙ)*

- Κουτσουρίδου Μαρία
- Αθανασίου Μαρία Άννα
